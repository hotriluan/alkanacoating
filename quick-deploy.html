🚀 Quick Deploy Guide

Triển khai Alkana Coating trong 5 phút

ℹ️ Hệ thống triển khai tự động
Tương tự WordPress Kickstart - Chỉ cần upload và click!
1

Build Package

Trên máy local, chạy script build:

Windows:

build-package.bat

Linux/Mac:

chmod +x build-package.sh
./build-package.sh

✅ Kết quả: File alkana-coating.zip và deploy.php

2

Upload Lên Hosting

Upload 2 files vào thư mục root:

  • 📦 alkana-coating.zip
  • 🔧 deploy.php
⚠️ Lưu ý: Upload vào thư mục public_html hoặc www tùy hosting
3

Chạy Installer

Truy cập wizard installer:

http://yourdomain.com/deploy.php

Wizard 6 bước tự động:

  1. Upload & kiểm tra requirements
  2. Giải nén package
  3. Cấu hình database
  4. Cấu hình website
  5. Chạy migrations
  6. Hoàn thành!
4

Cấu Hình Web Server

Tùy chọn A: Subdomain (Khuyến nghị)

  • Frontend: yourdomain.com → /frontend
  • Backend API: api.yourdomain.com → /backend/public

Tùy chọn B: Thư mục con

  • Frontend: yourdomain.com → /frontend
  • Backend API: yourdomain.com/api → symlink to /backend/public
ℹ️ File .htaccess đã được tạo tự động!
